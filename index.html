Base de datos compartida

Reúne el trabajo del equipo y consulta el consolidado territorial desde distintos dispositivos.

1. Conectar el proyecto

Ejecuta primero base_de_datos.sql en tu proyecto Supabase. Usa solo la clave pública publishable o anon.

2. Ingresar al equipo

El administrador crea las cuentas en Supabase. Los técnicos ven sus registros; la cuenta administradora ve el consolidado de todo el equipo.

Base en este navegador y respaldos

La base en este navegador guarda solo en este navegador. Conectar la nube no sube esos datos automáticamente.

El ejemplo de Roque se carga solo en la base de este navegador. Para registrar datos en la base compartida, inicia sesión y crea o completa la ficha allí. Un respaldo incluye todos los registros visibles en el modo actual.
